The project

Overview

The goal of the project was to design a coverage path planning algorithm for snow shoveling. The robot is required to cover the full space while leaving only the designated goal position uncleared. The planner must work for arbitrary obstacle layouts, start positions, and goal positions while respecting movement constraints such as no diagonal motion and a maximum 90-degree turn.

My role

I implemented and compared several coverage planning approaches, then selected a grid-based wavefront method that adds start and goal constraints and can generate and visualize candidate paths. The project included evaluating algorithmic tradeoffs and visualizing the resulting path generation and coverage behavior.

Technical approach

The system was implemented in Python and visualized using a custom grid-based environment. The approach uses a wavefront distance transform from the goal to assign cost values to cells, then constructs a path by traversing toward neighboring cells with the highest remaining distance value while maintaining obstacle and motion constraints.
