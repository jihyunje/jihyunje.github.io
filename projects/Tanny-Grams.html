Computer vision + robotics project · CS 134 · 2024

A robot that recreates a tangram configuration from a reference image by detecting pieces, mapping them into the real workspace, picking them up in sequence, and correcting placement errors.

Gallery

Project details

Overview

We built a robot capable of recreating a tangram configuration from an image. The system first identifies individual pieces and their center points, transforms those coordinates into the real-world workspace, locates the pieces physically, and then picks them up in sequence and places them at their target positions.

My contribution

I contributed to the robot system design and implementation for image-based piece detection, workspace mapping, and execution of the assembly task. The project also included recovery logic for misaligned pieces and a user interaction loop that allowed the robot to continue building even when some pieces were not detected.

Tools and methods

The project combined computer vision, robot perception, and manipulation planning. We used OpenCV-based detection and coordinate transforms to localize tangram pieces, then executed pick-and-place actions with a robotic arm to reconstruct the target configuration.
