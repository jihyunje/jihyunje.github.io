Shared-control painting assistant

Research · In progress · Sep 14, 2026

A system that assists people with tremor by blending user input and robotic stabilization to preserve user intent while improving stroke stability.

Gallery

Details

Overview

We aim to preserve the user's intended stroke while filtering tremor and offering optional guidance to complete shapes.

My contribution

Designed the control blending algorithm, implemented the demo UI, and conducted pilot user sessions.

Tools and methods

Hardware: 6-DOF manipulator, tablet input. Software: Python, ROS, and custom filtering algorithms.
