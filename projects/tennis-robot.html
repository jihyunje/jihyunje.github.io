The project

Overview

The goal of the project was to create a tennis-playing robotic arm that can react to a ball launched with random initial state and hit it toward a specified target. The robot has 6 degrees of freedom and uses inverse kinematics to orient the paddle at the appropriate contact point and timing.

My role

I helped build the robot model, define the task and controller logic, and implement the target contact planning so the arm could position itself and strike the ball toward the goal with a feasible joint configuration.

Technical approach

The system used a 6-DOF arm model, inverse kinematics, and physics-based ball dynamics with elastic collision modeling. The task was implemented so the robot could reason about the ball’s trajectory, compute an impact point along the path, and direct the paddle to send the ball to the target.
